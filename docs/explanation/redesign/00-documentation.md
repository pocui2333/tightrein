# 文档格式

tightrein 的全部文档按 Diátaxis 分为四类，每类有固定写法，不混写。

| 类型 | 读者在做什么 | 写法 | 目录 |
|---|---|---|---|
| 教程 | 第一次学，跟着做一遍 | 手把手，每一步都有可见的结果，保证能做成 | `docs/tutorials/` |
| 操作指南 | 要完成一件具体的事 | 前提、步骤、验证，不讲原理 | `docs/how-to/` |
| 参考 | 查字段、参数、命令 | 中性、完整、准确 | `docs/reference/` |
| 解释 | 想知道为什么这样设计 | 背景、取舍、原则 | `docs/explanation/`(含现有的 architecture、design、redesign) |

## 固定模板

- **操作指南**：目标、前提、步骤(每步给出命令与预期结果)、验证、常见问题。
- **方法参考**(方法目录中的每个方法)：一句话说明、适用条件、前提、参数表、输出、限制、示例配置。
- **契约参考**(扩展点、探针、交接文档等)：字段表(名称、类型、必填、说明、示例)，由对应的 JSON schema 自动生成，不手写，
  保证与代码一致。

## 给 AI 使用

skill 的参考资料直接引用同一份操作指南与参考文档，不另写一套内容。
