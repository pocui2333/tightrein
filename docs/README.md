# tightrein 文档

文档按 [Diátaxis](https://diataxis.fr/) 分为四类，按你的目的选择：

| 类别 | 适合什么时候读 | 入口 |
|---|---|---|
| 教程 | 第一次使用，想跟着做一遍 | [tutorials/](tutorials/README.md) |
| 操作指南 | 要完成一件具体的事 | [how-to/](how-to/README.md) |
| 参考 | 查配置项、命令、字段与方法 | [reference/](reference/README.md) |
| 设计 | 想知道为什么这样设计 | [explanation/](explanation/README.md) |

## 推荐阅读顺序

1. [教程：第一次运行](tutorials/first-run.md)：接入一个示例项目，运行第一次巡检。
2. [配置与运行说明](reference/configuration.md)：采集来源、审批关卡、预算、修复通道、agent 工具与模型。
3. [方法目录](reference/methods.md)：接入错误追踪、日志、告警与部署平台。
4. [设计](explanation/redesign/README.md)：各环节的决定与取舍。
